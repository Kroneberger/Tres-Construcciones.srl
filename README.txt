CONFIGURADOR DE VIVIENDAS — TRES PROPIEDADES

Cómo abrir:
1. Descomprimí la carpeta configurador_viviendas.
2. Abrí la carpeta desde Visual Studio Code: Archivo > Abrir carpeta.
3. Abrí index.html en el navegador. Recomendado: instalar la extensión Live Server y hacer clic en "Go Live".

Archivos:
- index.html: estructura de la página.
- style.css: diseño y estilos.
- script.js: selecciones y cambios de la vista previa.
- imagenes/casa-demo.svg: ilustración de ejemplo.

Importante:
La vista de cocina/baño es una maqueta visual hecha con CSS, no un render arquitectónico real. Para usar renders propios, agregá las imágenes en la carpeta imagenes y después adaptamos el código para usar imágenes base, máscaras y texturas de materiales. Una imagen plana común no permite cambiar de manera realista solo el piso o la mesada sin preparar esas zonas por separado.


ACTUALIZACIÓN DE PORTFOLIO
- El Inicio ahora tiene un carrusel de cinco renders que cambia cada 7 segundos.
- Se puede navegar con flechas e indicadores; al pasar el cursor el carrusel se pausa.
- La sección Portfolio muestra los renders recibidos, clasificados por tipo de trabajo.
- Las imágenes están dentro de la carpeta imagenes. Para agregar renders, copiá los archivos allí y agregá una diapositiva o tarjeta en index.html.
- Los renders de cocina/interiores se muestran como imágenes de portfolio; la personalización actual sigue siendo una vista conceptual por colores, todavía no modifica las texturas dentro de un render real.


Actualización: identidad TRES PROPIEDADES, logo institucional en encabezado y pie, carrusel de Inicio con desplazamiento lateral y renders reales en la vista previa de materiales. La tonalidad del render es orientativa: para modificar cada superficie por separado se requieren máscaras o renders alternativos específicos.
